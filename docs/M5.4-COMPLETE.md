# M5.4 COMPLETE — Photo Submission

Status: FROZEN on develop after manual QA.

## Architecture
- New-place photos are staged separately from canonical `campground_photos`.
- Private Storage bucket: `campground-submissions`.
- Metadata table: `campground_submission_photos`.
- Pending photos have no public delivery path.
- Canonical promotion is deferred to the moderation/approval workflow.

## Controls
- Server-controlled upload endpoint: `POST /api/submissions/campgrounds/photos`.
- Submission must exist and remain `pending`.
- JPEG, PNG, WebP only.
- Maximum 8 MiB per photo.
- Maximum 5 photos per submission.
- Server-generated object paths.
- Metadata defaults to `pending`.
- Storage object is removed if metadata persistence fails.
- anon/authenticated have no direct staging-table privileges.
