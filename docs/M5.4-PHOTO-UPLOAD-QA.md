# M5.4 Photo Upload API QA

Prerequisites: migration 0011 applied, verifier 7/7 PASS, local server secret configured.

The endpoint accepts one photo per request after the campground submission exists:
`POST /api/submissions/campgrounds/photos` multipart fields `referenceCode` and `file`.

Expected controls:
- pending submission only;
- JPEG/PNG/WebP only;
- maximum 8 MiB per file;
- maximum 5 photos per submission;
- private `campground-submissions` bucket;
- metadata status `pending`;
- no public URL returned;
- storage object removed if metadata insert fails.

M5.4 wizard integration will submit campground data first, then upload selected photos against the returned ICL reference.
