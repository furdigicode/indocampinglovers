# M4.1 — Geographic Routing Contract

## Goal
Create stable, human-readable, SEO-safe geographic landing routes for discovering published campgrounds by Indonesian province and regency/city.

## Canonical public routes
- National directory: `/camping`
- Province: `/camping/{province-slug}`
- Regency/city: `/camping/{province-slug}/{regency-slug}`
- Campground detail remains: `/camping/{campground-slug}`

## Important route collision rule
The one-segment namespace `/camping/{slug}` is shared by campground detail and province landing pages.

Resolution contract:
1. if `{slug}` matches a valid province slug, render the province landing page;
2. otherwise resolve `{slug}` as a campground detail slug;
3. if neither exists, return 404.

Province slugs are therefore reserved and MUST NOT be assigned to campground records.

Examples:
- `/camping/jawa-tengah` → province landing
- `/camping/jawa-tengah/kabupaten-semarang` → regency landing
- `/camping/icl-qa-m3-detail` → campground detail

## Geographic source of truth
Use existing reference tables:
- `provinces`
- `regencies`

Campground eligibility continues to use the public directory rules:
- campground must be `published`;
- RLS remains authoritative;
- geography must resolve through the campground's province/regency references;
- no unpublished record is exposed to make an SEO page appear populated.

Do not derive canonical geographic slugs from display labels at request time when reference-table slugs are available.

## Empty / invalid geography
- unknown province slug → continue campground-detail resolution for the one-segment route; 404 if no campground matches;
- known province with zero published campgrounds → valid geographic page, but apply `noindex,follow` until it has useful directory content;
- unknown regency slug under a valid province → 404;
- regency belonging to a different province → 404;
- known regency with zero published campgrounds → valid page with `noindex,follow`.

## Query parameters
Geographic pages may reuse M2 directory query parameters for discovery UX (type, facility, access, price, sort, page, view, q).

Canonical SEO URL excludes transient filter/query parameters. Filtered variants should not create independent canonical landing pages.

## Breadcrumb contract
Province:
`Camping > {Province}`

Regency/city:
`Camping > {Province} > {Regency/City}`

Campground detail will later gain geographic breadcrumbs without changing its canonical detail URL.

## Metadata contract
Province title intent:
`Tempat Camping di {Province} | IndoCampingLovers`

Regency title intent:
`Tempat Camping di {Regency}, {Province} | IndoCampingLovers`

Descriptions must be generated from known geography and actual public result counts. Do not invent attractions, climate, scenery, facilities, or local claims from the geographic name alone.

## Canonical contract
Canonical URLs are built from `NEXT_PUBLIC_APP_URL` plus the canonical route.

Expected:
- province canonical → `/camping/{province-slug}`
- regency canonical → `/camping/{province-slug}/{regency-slug}`

Query/filter variants canonicalize to the base geographic landing URL.

## Internal linking
- `/camping` should expose links to useful province pages.
- province pages should expose links to their regency/city pages that have published campground results.
- campground detail should later link back through its geographic hierarchy.

## Sitemap eligibility
Later M4 sitemap work should include:
- province pages with at least one published campground;
- regency/city pages with at least one published campground;
- published campground detail pages.

Empty geography pages remain valid for direct navigation but are excluded from sitemap and marked `noindex,follow`.

## Out of scope for M4.1
- UI implementation;
- sitemap implementation;
- JSON-LD implementation;
- editorial destination copy;
- near-me/geolocation;
- PostGIS;
- district/subdistrict routes;
- automatic redirects for renamed administrative areas.

## Acceptance criteria
- canonical route hierarchy is frozen;
- detail/province one-segment collision has deterministic resolution;
- province slugs are reserved from campground use;
- invalid province/regency relationships cannot render misleading pages;
- empty geographic pages have explicit indexing policy;
- filtered URLs do not become duplicate canonical pages;
- no RLS/browser grant relaxation is required.
